Music App
Flutter app using ITunes Search API

Features:
- Clean,modern UI
- View track details
- Play different songs from a fixed list.

Technical Decisions:
API:- Used Itunes' API instead of Deezer due to CORS restriction during development.

Limitations:
- Fixed genre of songs
- Limited error handling
- Basic state management
- No search functionality

What I Learned:
- Async handling
- JSON parsing
- Use of APIs
- Lazy loading with Listview.builder

Tech stack:
- Flutter
- Dart
